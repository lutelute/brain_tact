# brain_tact アプリ化計画 — シンプル・洗練

> 原則は **引き算**。機能を足さない。「見る」と「促す」の2つだけを、美しく。

## アプリの本質 — 1画面で完結

ダッシュボード1枚が brain_tact アプリ。それ以上は作らない。

- 全セッションが**一目**でわかる(状態を色で、改善が要るものが浮かぶ)
- 各セッションに**主要アクションは1つ**(🔬 改善を促す)
- 常に**最新**(自分で更新ボタンを押さない)

## やること(これだけ)

1. **リアルタイム化** — 15秒ポーリングをやめ、変化した時だけ静かに更新(SSE)
2. **1行 = 1セッション = 1ボタン** — 状態と「次の一手」だけ。詳細はクリックで控えめに開く
3. **洗練** — 既存のロゴ・余白・モノスペースで、静かで密度の高い画面に

## 追加(2026-06-12): ミニ監視窓

「全体監視が行き届かない」(ユーザー)対策として、唯一の例外を追加:
**/mini** — 常に最前面の簡易窓(Electron)。tray クリック / ⌘⇧B でポップアップ、
1行=1セッション(重要度順)、表示中は90秒ごと自動再スキャン、↻UIで再読み込み。
機能は足さない(見るだけ+フル版への導線)。

## やらないこと(意図的に削る)

- 統計グラフ・設定画面・複数ウィンドウ(ミニ監視窓は上記の唯一の例外)
- 配布パッケージ(当面ブラウザでよい)
- リモート監督・複雑な分析・通知の多重化

足すほど散らかる。brain_tact 自身が「散らかりを嫌う」道具なのだから、UIも散らかさない。

## 形態

- **当面**: ブラウザで開く1画面(localhost:8787)。これがアプリ。
- **将来**: 同じ1画面をそのまま Tauri でラップすれば `.app` になる。中身は変えない。

## 進め方

リアルタイム化 → 1行1ボタンへの整理 → タイポ・余白の洗練。
3つ終えたら「アプリ」として完成とする。**増やさないことが完成条件**。

> 機能の賢さ(判定・改善ループ)は [ROADMAP.md](../ROADMAP.md) で別管理。
> 本計画は「UIを簡素に保つ」ことだけが目的。
